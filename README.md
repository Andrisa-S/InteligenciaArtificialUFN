# 🤖 Inteligência Artificial — UFN

Repositório com conteúdos e exercícios desenvolvidos durante a disciplina de Inteligência Artificial do curso de Ciência da Computação na **Universidade Franciscana (UFN)**.

O repositório reúne implementações práticas de diferentes abordagens da IA — desde métodos de busca e algoritmos evolutivos até redes neurais — utilizando múltiplas linguagens conforme o paradigma mais adequado a cada tema.

---

## 📚 Conteúdos abordados

### 🔍 Métodos de busca
Estratégias para exploração de espaços de estados e resolução de problemas, base para diversas técnicas de IA.

### 🧬 Algoritmo Genético
Técnica de otimização inspirada na evolução natural, utilizando conceitos como população, seleção, cruzamento e mutação para buscar soluções aproximadas em problemas complexos.

### 🧠 Redes Neurais
Introdução aos fundamentos de redes neurais artificiais, explorando sua estrutura e funcionamento como modelo computacional inspirado no cérebro humano.
